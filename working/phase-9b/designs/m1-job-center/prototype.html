Phase 9b — Job Center prototype

Reference design for the M1 design gate. Reusable token-only composition; no new colors, no new runtime deps.

1. ActionBar trigger button

Replaces Phase 9a's .action-bar-operation-badge. The inline count chip shows non-terminal operation count (queued + running + cancel_requested). Hidden when 0; "9+" when > 9. The 9a .action-bar-operation-pill (last-completed) is REMOVED in 9b — its info lives in the tray's Recent section.

2. Status pill catalog

Seven OperationStatus variants. All composed with color-mix() against existing tokens (accent / success / warn / error / ink-muted) plus non-color cues (border style, dot shape) so the design is colorblind-safe.

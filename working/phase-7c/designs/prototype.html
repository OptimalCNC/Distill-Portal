Motion budget & token discipline

All expand/collapse uses native <details> with the existing --motion-disclosure (200 ms) block-size transition authorized by Phase 5 M2b. The chip-tag pill is a static Fraunces italic small-caps marginalia — not animated. The sienna inline-start rail on lifecycle cards is static; it does not pulse, slide, or fade.

Reduced-motion: every transition listed above zero-outs via the global @media (prefers-reduced-motion: reduce) rule in apps/frontend/src/styles/global.css. The disclosures snap; the visual layout is unchanged.

Tokens consumed: surface, surface-raised, ink, ink-muted, border, border-strong, accent, success, warn, error, space-1..space-8, radius-sm, radius-md, font-display, font-chrome, font-mono, text-xs/sm/base, leading-comfortable, measure, motion-disclosure, ease-in-out. Zero new tokens. Zero new hex.

Notes
-----
- The disclosure animation: 200 ms ease-in-out on block-size, via the
  global `interpolate-size: allow-keywords` rule (from M2b global.css).
- The summary text rotates from "▸ Expand (N more bytes)" to "▾ Expand
  (N more bytes)" — same string, different disclosure marker (browser-
  native rotation).
- The tail <pre> uses class `msg-tool-pre msg-tool-result-tail` with
  `margin-top: 0` to flow continuous with the head.
- State persists across tab switches (M2b keep-mounted contract). User
  expands once, switches to Metadata, returns to Transcript — disclosure
  is still open.
- State resets on selectedRowKey change (parent SessionView remounts).

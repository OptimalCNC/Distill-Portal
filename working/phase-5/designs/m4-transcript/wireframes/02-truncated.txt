Notes
-----
- Banner copy is verbatim from spec line 715. "Open raw" is bolded TEXT,
  not a hyperlink — the actual link lives in the session header.
- Banner uses warn 8% mix background + 3 px solid warn stripe on the
  inline-start edge. NO icon, NO close button. The capacity fact persists;
  dismissing the banner without dismissing the truncation would mislead.
- Banner mounts with opacity 0 → 1 over --motion-base (120ms) ease-out.
  STATIC color-mix background — only opacity animates.
- Trailing "· · ·" marker is purely a visual cue that the stream stopped at
  the cap. Decorative; aria-hidden.
- ARIA: role="status" on the banner; screen readers announce politely.

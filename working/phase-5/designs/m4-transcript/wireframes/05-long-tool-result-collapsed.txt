Notes
-----
- TOOL_RESULT_OVERFLOW_BYTES = 2048 (declared in TranscriptView.tsx).
- Discriminator: msg.bytes > 2048 (parser-computed UTF-8 byte count).
- Split-point: TextEncoder.encode(msg.text), find byte 2048, walk back to
  a UTF-8 codepoint boundary (continuation bytes start with 10xxxxxx),
  TextDecoder.decode the head and tail.
- "Expand (Nmore more bytes)" copy verbatim from spec line 708, where
  Nmore = msg.bytes - 2048.
- The disclosure summary uses --color-accent (the M4 surface that consumes
  accent as an emphasis affordance — NOT a hyperlink, but the color reads
  as "interactive").
- Hover state: text-decoration underline (INSTANT, no transition).
- ARIA: native <details> inherits all keyboard support.

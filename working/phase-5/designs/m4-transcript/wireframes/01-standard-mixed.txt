Notes
-----
- User panels carry the 5% accent tint (warm amber wash); assistant panels sit
  on the bare warm-paper surface. The differential reads as turn-taking without
  needing avatars or labelled rails.
- The 70ch reading measure caps the panels regardless of viewport width.
- Code blocks inside assistant prose use surface-raised + mono.
- The tool_use / tool_result panel pair shares the hairline-bordered chrome —
  same recipe, different header label.
- The system message at the bottom carries no panel chrome — single muted line.
- Spacing rhythm (3 magnitudes): 16px default between any two adjacent
  messages (the floor for non-boundary kind-changes); 24px override between
  adjacent SAME-kind messages (user→user, assistant→assistant, tool_use→
  tool_use, tool_result→tool_result, system→system); 32px breathing only
  around boundary messages (not depicted in this wireframe — see wireframe
  04). This wireframe shows the 16px default firing on every transition
  because there are no adjacent same-kind pairs in this scenario. NOTE:
  tool_use → tool_result is a kind-change (different MessageKinds) and uses
  16px, NOT 24px — same-kind override matches per-kind exactly.

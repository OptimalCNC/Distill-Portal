M4 — Wireframe 04 — Boundary chapter-break (signature detail #1)
================================================================

Scenario: boundary message appears between two turns. Could be a session-resume
boundary (codex /resume) or a compaction boundary (claude-code conversation
compaction). NEVER merged with neighbors.

Recipe: full-width 1 px hairline at --color-border-strong, centered Fraunces
italic small-caps label at --text-sm --color-ink-muted, 32 px breathing top
and bottom. SHARED with M5's Skim view boundary block.

Implementation
--------------

  HTML:
    <li class="msg msg-boundary" role="separator" aria-orientation="horizontal">
      <span class="msg-boundary-rule msg-boundary-rule-start" aria-hidden="true"></span>
      <span class="msg-boundary-label">SESSION RESUMED</span>
      <span class="msg-boundary-rule msg-boundary-rule-end" aria-hidden="true"></span>
    </li>

  CSS:
    .msg-boundary {
      display: grid;
      grid-template-columns: 1fr auto 1fr;
      gap: var(--space-4);
      align-items: center;
      margin-block: var(--space-8);
      max-inline-size: none;        /* expand past the 70ch reading column */
    }
    .msg-boundary-rule {
      block-size: 1px;
      inline-size: 100%;
      background: var(--color-border-strong);
    }
    .msg-boundary-label {
      font-family: var(--font-display);
      font-style: italic;
      font-variant: small-caps;
      font-size: var(--text-sm);
      color: var(--color-ink-muted);
      letter-spacing: 0.18em;
      padding: 0 var(--space-3);
    }

Notes
-----
- The chapter break NEVER carries a timestamp. It is editorial, not
  chronological. The next user message after the boundary carries its own
  timestamp.
- The wrapper has role="separator". The label is in DOM order so screen
  readers announce "separator: SESSION RESUMED".
- Same recipe MUST be reused by M5's SkimView boundary block. Any drift
  is a regression against signature detail #1.
- Copy strings: "SESSION RESUMED" (boundarySubtype === "session_resumed")
  / "CONVERSATION COMPACTED" (boundarySubtype === "compacted"). Uppercase
  in source — Fraunces small-caps glyph set is exercised on uppercase input.

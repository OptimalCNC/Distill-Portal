    1. ASSISTANT · 2 minutes ago
      SkimView reuses TranscriptView verbatim, scoped to a messageIndex range via the new `messageRange` prop. The prop is optional — when omitted, behavior is identical to M4's contract.
    2. ASSISTANT · 2 minutes ago
      For an Agent reaction disclosure: `messageRange = {start: block.start + 1, end: block.end}` (excludes the user message at block.start). For an agent_only block: `messageRange = {start: block.start, end: block.end}` (full range).
    3. ASSISTANT · 2 minutes ago
      Defensive clamping handles out-of-range values: `lo = Math.max(0, start)`, `hi = Math.min(messages.length - 1, end)`. If `hi < lo`, the slice is empty and TranscriptView renders "No messages parsed." (spec line 697 — never silently blank).

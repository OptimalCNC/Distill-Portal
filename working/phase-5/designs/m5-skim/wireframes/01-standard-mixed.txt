=================================================

oversized_user_message (collapsed). Skim tab activated; SkimView mounted
inside .session-pane.

edge-to-edge of the stream container.

Notes
-----
- Three-magnitude rhythm:
  - 24px (--space-6) between same-kind adjacent skim blocks (e.g., user_turn
    -> user_turn).
  - 32px (--space-8) between different-kind adjacent skim blocks (e.g.,
    user_turn -> agent_only, user_turn -> oversized).
  - 32px (--space-8) breathing above + below boundary blocks (overrides
    same-kind / kind-change rules).
- The user_turn panels carry the 5% accent tint (warm amber wash) — same
  recipe as M4 .msg-user. The agent_only panel sits on the bare warm
  surface with a hairline border.
- The oversized_user_message has NO panel background — only the 4px warn
  left stripe. The summary is on .text-sm chrome at .color-ink (NOT
  ink-muted — the size signal warrants stronger ink than the
  agent-only summary).
- The boundary block is byte-equivalent to M4's chapter break (signature
  detail #1). Same Fraunces italic small-caps label, same 1px hairline
  rules, same 32px breathing.
- Skim-block stagger animation: 40ms × min(idx, 8) delay; opacity 0→1 +
  translateY(4px → 0) only. Reduced-motion zeroes via global rule.
- All <details> elements are CLOSED by default (planner Q2). User opts in
  to read each agent reaction.
- Spec-literal copy:
  - "Agent reaction (3 messages)" / "(5 messages)" — verbatim per-block.
  - "Summary disabled — generation deferred to a later phase. Use
    \"Expand to raw messages\" to read the agent's response inline." —
    verbatim spec line 687.
  - "Expand to raw messages" — verbatim summary inner text.
  - "Agent-only session (12 messages)" — verbatim spec line 693.
  - "Oversized user message (78 KB) — collapsed by default" — verbatim
    spec line 695. KB = Math.round(meta.sizeBytes / 1024).
  - "SESSION RESUMED" — verbatim per spec line 691 + Resolved Decision #16.

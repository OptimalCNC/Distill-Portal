NOTES:
- "[3 active]" chip suppressed when count === 0 (rendered with `hidden`
  attribute -- both visually invisible AND removed from accessibility
  tree).
- Chip suppressed on the summary when count === 0 -- summary then reads
  "Filters" alone with the chevron.
- Default open state is governed by a matchMedia listener
  ("(min-width: 1100px)") mirroring App.tsx narrow-mode listener at
  lines 800-826. The user's manual toggle below 1100 px is preserved
  (the listener does NOT clobber it on intra-breakpoint resizes).
- Browser-native open/close is INSTANT -- no CSS transition added
  (the <details> block-size exemption per spec line 1100 is deferred
  to M5 SkimView).

INTERACTION:
- Tab focuses the <summary>; Enter/Space toggles.
- Focus-visible: 2 px solid var(--color-accent) outline, 2 px offset
  (parallel to M1a's .back-to-list).
- When closed, the filter chips inside the body are NOT in Tab order
  (browser-native).

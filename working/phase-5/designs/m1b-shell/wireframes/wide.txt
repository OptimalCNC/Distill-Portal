KEY CHANGES VS M1a:
- Table compresses 8 cols -> 5 cols.
- ActionBar + Pagination relocate from inline panels into
  .list-pane-footer (sticky strip at bottom).
- Filter strip wraps inside <details> below 1100 px (above 1100 px
  the strip reads as the existing Phase 4 inline strip -- no <details>
  chrome visible).
- Session pane gains the vestigial "Open detail" text-link button
  in the ready-placeholder state. Row click no longer auto-mounts
  the drawer.

ARCHIVE-ROOM AESTHETIC:
- Hairlines, no shadows.
- One accent (sienna) used surgically: selected-row tint (8%) + 2 px
  inset left edge; deep-link pulse keyframe peak (22%); chip active
  state (15% bg + 70% text + 35% border); focus-visible outlines.
- Sharp panels (no rounded outer corners on the split-pane shell);
  4 px radius preserved on buttons + status pills.
- Quiet typography: system-sans body; mono for rowKey + tool badge +
  Updated cell (column alignment).

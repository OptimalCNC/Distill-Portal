Typography

Three roles. Display sets the editorial tone; chrome carries every chip, table, and button; mono is reserved for code and data identifiers. Fraunces is self-hosted (~80 KB woff2 subset) with size-adjust and ascent-override tuned to Charter so the system fallback takes over without layout shift if the woff2 fails to load.

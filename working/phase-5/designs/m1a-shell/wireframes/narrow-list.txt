Notes:
  - Default narrowMode on first mount: "list".
  - Tapping a row sets narrowMode = "session" (transitions to the
    next wireframe, narrow-session.txt) and sets `selectedRowKey`.
    Both happen synchronously in the same React update.
  - The list pane has NO `border-right` here (the rule fires only
    above 900 px).
  - Selected-row treatment is identical to wide viewport — the user
    sees which row is "current" even when the session pane isn't on
    screen. This is the key Phase-5-vs-Phase-4 affordance: the user
    can return to the session pane without re-clicking the row.

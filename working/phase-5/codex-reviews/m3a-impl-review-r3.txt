   360	### User-turn boundary algorithm

   362	`buildSkim(messages, threshold)` walks the message stream once with **two explicit open-region trackers** (no shared `currentTurnStart` variable):
   363	
   364	```ts
   365	let openUserTurnStart: number | null = null;
   366	let openAgentOnlyStart: number | null = null;
   367	const blocks: SkimBlock[] = [];

   369	
   370	All `start` / `end` values index into `messages[]` (`messageIndex`), NOT raw line numbers (`lineOrdinal`).
   371	
   372	1. Empty stream → return one `agent_only` block with `start: 0, end: -1, meta: {empty: 1}`.
   373	2. For each message at `messageIndex i` in order, dispatch on `kind`:
   374	   - **`boundary`**: close any open region (user_turn AND/OR agent_only) at `i-1`, then emit `{kind: "boundary", start: i, end: i, meta: {subtype: msg.boundarySubtype}}`. Both trackers reset to null.

   377	   - **`assistant` / `tool_use` / `tool_result` / `system` / `unknown`**:

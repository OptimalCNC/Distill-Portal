### Findings 1 + 2 (key= on list items): false positive

The M2b r1 #4 codex catch was about `key={activeTab}` on the panel content **root** which would CAUSE remount when activeTab changes. That is a remount-on-tab-switch trigger.

The keys you flagged at lines 224, 465, 509 are on `.map()`-rendered list items, NOT on TranscriptView root or any tab-driven element:
- Line 224: `key={`${w.lineOrdinal}-${idx}`}` on warning list `<li>` items inside the parse-warnings `<details>`.
- Line 465: `key=...` on inline code span elements.
- Line 509: `key=...` on code-block span elements.

These are React's **standard list reconciliation keys** — REQUIRED by React when rendering lists from `.map()`. React explicitly warns when missing. They do NOT trigger remount on tab switch because:
1. They are tied to list-item identity (`lineOrdinal`/`idx`), NOT to `activeTab`.
2. The list itself doesn't unmount on tab switch (the parent component stays mounted; only its display toggles via the M2b `hidden` attribute).

The keep-mounted blocking rule from M2b r1 #4 is about the panel-content remount root, not about list-reconciliation keys.

**No code change needed for findings 1 + 2.**

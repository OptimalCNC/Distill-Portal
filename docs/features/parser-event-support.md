# Parser Event Support Matrix

Phase 7a audited the local Claude Code and Codex JSONL corpora and mapped each observed discriminator tuple to a parser route, transcript treatment, and representative fixture. Phase 7b applied the parser audit decisions in this matrix.

The matrix is now a living support table. Rows marked `✅ supported` either emit a timeline message/boundary or intentionally preserve a structured parser warning for genuine malformed or drifted data. Rows marked `🔇 silenced` are expected metadata/telemetry/control records that the parser handles explicitly without rendering a timeline row and without warning. Some supported rows include render-treatment notes for Phase 7c, but their parser support status is closed in Phase 7b.
